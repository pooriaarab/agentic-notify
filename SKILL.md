# agentic-notify

Notifications for humans and agents. At 0.0.0 only the scaffold exists.

## Use the CLI

```sh
npx agentic-notify --version
```

## Use the MCP server

Start the server with `npx agentic-notify mcp`. Call `ping` to check it.
